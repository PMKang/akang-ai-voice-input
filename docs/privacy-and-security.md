# 隐私与安全

本文描述 Noboard · 自在说当前 macOS 版本的数据边界。它不是法律意义上的隐私政策，而是便于开发者审计实现的技术说明。

## 数据流

1. 麦克风音频由 AVAudioEngine 在本机采集。
2. 音频在内存中转换为 `16 kHz / 单声道 / PCM16`。
3. 音频片段通过加密 WebSocket 发送到用户自行配置的阿里云百炼 Workspace。
4. 模型返回最终文字后，应用尝试写入当前输入框。
5. 无法写入时，根据用户设置复制到系统剪贴板。

阿康的 AI 语音输入法不是离线识别工具。使用语音输入即表示音频需要发送到模型服务处理。

## 本地保存

### Keychain

以下内容保存在 macOS Keychain：

- 各模型服务的个人 API Key
- 可选崩溃上报的入口令牌

Keychain 服务标识为 `com.akang.ai-voice-input`，可在设置页主动移除。

### Application Support

以下内容以 JSON 保存在 `~/Library/Application Support/AkangVoiceInput/app-data.json`：

- 最终文字历史记录
- 录音时长和处理耗时
- 使用的模型名称
- 手动个人词典

文件使用原子写入，减少中途退出造成损坏的概率。

为识别上次是否异常退出，应用还在同一目录保存一份最多 160 条的脱敏诊断环形日志。开启崩溃上报后，发送失败的报告最多在本机保存 20 份；队列文件权限为仅当前用户可读写。关闭上报开关会清除待发送队列。

### UserDefaults

以下偏好保存在 UserDefaults：

- Workspace ID
- 快捷键
- 默认语言
- 粤语转换开关
- 剪贴板回退开关
- 崩溃上报开关（默认关闭）

## 不保存的内容

- 原始音频文件
- Base64 音频片段
- 完整 WebSocket 请求与响应
- Authorization 请求头
- API Key 或 Workspace ID 明文日志
- 转写正文诊断日志

## 诊断与可选崩溃上报

诊断事件在内存中最多保留 100 条，并将最多 160 条脱敏事件写入 Application Support，以便下次启动判断上次是否异常退出。报告记录：

- 连接、录音、响应和输出阶段
- 权限状态
- 录音与处理耗时
- 最终文字长度
- Token 数量
- 错误摘要

复制或入队前会脱敏用户名路径、邮箱、Bearer、常见密钥格式、Workspace ID 和 WebSocket 主机。正常退出会写入完成标记；诊断环形日志不会包含转写正文。

macOS 的“自动发送脱敏崩溃报告”默认关闭。用户主动开启后，应用会在下一次启动时检查上一轮运行时段内匹配本应用的 macOS `.ips`，只提取异常类型和应用栈；不会上传原始 `.ips` 文件。若没有匹配报告，则发送“异常退出”与最后的脱敏运行事件。发送失败时保留在本机队列，后续启动或手动重试。

远端链路为 `Noboard → Cloudflare Worker → D1 → 飞书群机器人`。Worker 会再次校验、脱敏和去重；同一问题的普通重复只累计次数，新问题、已解决问题复发和人工测试才推送飞书。D1 保存脱敏后的版本、系统环境、错误摘要、应用栈和最多 40 条 breadcrumb。飞书消息不包含完整栈或 breadcrumb。

飞书 Webhook 只作为 Worker Secret 保存，不进入客户端。独立的上报令牌同时保存在 Worker Secret 与当前 Mac Keychain，用来拦截没有令牌的伪造请求。令牌和 Webhook 均不得写入源码或提交记录。

需要明确：客户端令牌不是设备证明。当前方案适合个人使用或受控测试分发；若将来面向公众发行并预置同一枚令牌，攻击者仍可能从运行中的客户端提取它。公开发行前应改为每安装注册和轮换凭证，并继续保留服务端限流、告警去重与异常流量监控。

## 系统权限

- 麦克风：采集用户主动开始的语音。
- 辅助功能：将最终文字写入当前焦点输入框。

若辅助功能未授权或目标输入控件不支持安全写入，应用不会覆盖控件全部内容，而是使用剪贴板回退。

## 开发安全检查

提交前至少执行：

```bash
git diff --check
swift test
git status --short
git remote -v
```

还应扫描常见密钥前缀、Bearer 请求头、私有主机和个人标识，并人工检查新增截图和文档。

## 当前发布状态

- 仅提供本地临时签名的开发构建。
- 尚未进行 Developer ID 签名、公证或 App Store 沙箱适配。
- 公开提交前需要执行敏感信息扫描，并人工检查新增截图与文档。
