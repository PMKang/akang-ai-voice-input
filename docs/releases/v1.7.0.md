# v1.7.0 — Custom shortcuts on Windows

Released on 2026-07-28.

## Windows

- Added a shortcut settings dialog with presets and a custom key-capture mode.
- Added support for Left Alt, Right Alt, function keys, and user-defined modifier combinations.
- New installations default to Left Alt while existing shortcut settings remain unchanged.
- Added validation for unsafe bare keys, Windows-reserved combinations, and shortcuts already occupied by another application.
- A new shortcut is saved only after Windows successfully registers it; cancelling or failing registration restores the previous working shortcut.

## macOS

- Rebuilt from the same tag with the unified `1.7.0` product version.
- No functional changes in this release. Custom shortcut configuration will be implemented separately and published in a later unified release.

## Verification

- Windows solution builds in Release configuration without warnings.
- All Windows automated tests pass.
- Custom capture, occupied-shortcut rejection, cancellation, and previous-shortcut restoration were verified on Windows 10 22H2.
