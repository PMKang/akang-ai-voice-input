# Noboard · 自在说 v1.8.0（macOS）

本次为 macOS 独立更新；Windows 暂保持 v1.7.0，待完成真实设备验证后再更新。

## 重点更新

### 1. 悬浮语音输入不再固定挡住底部操作

- 展开态可通过明确的拖动把手移动，拖动采用原生窗口行为，减少闪动和滞后。
- 鼠标移入拖动把手或收起按钮时会有蓝色反馈和文字提示，降低首次使用的理解成本。
- 支持展开条、收起胶囊和贴边球三种状态；拖向屏幕外侧才会贴边，普通移动不会误收起。
- 收起态保留动态波形、录音时长和一小段最新文字；可在设置中关闭收起态实时文字。

### 2. 位置和状态会被记住

- 首次使用默认在屏幕底部居中出现。
- 用户主动拖放后，下一次快捷键唤起会恢复最后的位置，以及展开或收起状态。
- 录音、停止后的“正在处理”和收起态围绕同一个位置锚点变化，不会在状态切换时跳回默认位置。
