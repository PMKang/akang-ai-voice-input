# Noboard · 自在说 v1.10.0（macOS）

## 改进

- 统一模型范围与统计周期筛选，首页卡片、热力图和右侧统计始终使用同一筛选条件。
- 全部历史热力图按自然月连续展示，并支持横向查看更早月份；单月视图自动放大热力图格子，减少空白。
- 未返回 Token 的记录继续显示为“暂不支持”，不再把未知数据误报为 0。
- 模型配置页提供对应官方 API 配置文档入口。
- 扩大月份 Tab 的点击命中区域。
