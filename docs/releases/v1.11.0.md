# Noboard · 自在说 v1.11.0（macOS）

## 新增

- macOS 崩溃后自动读取系统生成的 `.ips` 报告，并在下次启动时后台脱敏上报。
- 崩溃报告通过 Worker 发送到飞书，包含异常类型、信号、调用栈、版本和系统信息。
- 新的崩溃指纹自动创建 GitHub Issue；同一问题再次出现时追加评论并累计次数。
- 开发者测试崩溃也可以验证完整的飞书与 GitHub Issue 链路，并明确标记为测试报告。

## 安全与发布

- 上报过程不读取用户密码、模型 API Key、音频或转写正文。
- GitHub 与 Worker 凭证只保存在服务端，不进入客户端源码。
- 正式 Release 构建不包含“模拟崩溃（测试）”入口。

## 验证

- `swift test`（79 个测试通过，1 个按设计跳过）
- Worker `npm run typecheck && npm test`（9 个测试通过）
- Release 二进制检查：不包含测试崩溃符号和测试文本。
