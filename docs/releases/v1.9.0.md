# Noboard · 自在说 v1.9.0（macOS）

## 本次更新

- 弱网时，语音波形仍在采集但服务端迟迟未返回文字，会提示“当前网络环境差，可能会花超出平时的更多时间，请耐心等待”。
- 完全断网时，不再闪退或无提示地结束；界面会明确提示“检测到断网，请连接网络后再使用”。
- 实时识别发送改为按录音顺序排队，避免网络抖动下应用侧并发发送带来的顺序不确定性。
- 录音过程中可点击关闭按钮取消本次识别：停止采集、不输出文字、不写入历史，也会忽略迟到的识别回调。

## 验证

- 使用 macOS `Network Link Conditioner` 的 Very Bad Network 配置验证：1 Mbps 上下行、10% 丢包、500 ms 延迟。
- 完全断网与恢复网络的状态均已单独验证。
