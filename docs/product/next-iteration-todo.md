## P0：悬浮语音输入反馈（先做）

- 将语音输入悬浮条支持为三个当下交互状态：展开横条、收起胶囊、贴边圆球。
- 三种状态均可拖动；拖动后吸附到屏幕边缘或角落，并记住用户位置。
- 收起胶囊显示动态声波、简短实时文字（约 10–16 个字）和展开控件；不显示完整转写。
- 贴边圆球支持向屏幕内侧伸出一行“字幕尾巴”；需要完全让位时可只保留圆球。
- 实时文字以短语替换/淡入方式更新，不使用跑马灯；声波跟随实际音量。
- 提供隐私选项：收起态显示实时文字 / 仅显示录音状态。

## P1：长时间静音后会话断开

- 先增加不记录音频和转写正文的诊断：最后一次音频发送时间、最后一次服务端消息时间、WebSocket 关闭/错误摘要。
- 为默认 Qwen Realtime 分支补齐经官方协议验证的保活机制，并加入静音超过 60 秒后恢复说话的回归测试。
- 不把“保活”与“自动继续录音”混为一谈：用户主动停止时必须立即终止会话。

## P1：崩溃可追溯性

- 增加本地持久化的崩溃前运行日志（环形、脱敏、限制容量），覆盖启动、录音状态切换、音频设备变化、网络状态和未处理错误摘要。
- 下次启动时检测上次是否异常退出，并在“诊断”页面提供查看、复制与清除。
- 明确日志不写入 API Key、Workspace ID、原始音频或转写正文。
- 先收集至少一次真实崩溃报告，再定位并修复具体闪退原因；不要在没有证据时猜测修复。
