# AI语音输入卡住时，别让用户干等

时长目标：约 38 秒；画幅：1080 × 1440，30fps。

| 时间 | 口播 | 画面 |
|---|---|---|
| 0–5秒 | AI语音输入最烦的不是慢。 | `00:07` 数字从 `00:00` 跳到 `00:07`；声波快速跳动，文字区域保持为空。 |
| 5–10秒 | 是声波还在跳，文字却迟迟不来。 | 反差文案和真实弱网界面。 |
| 10–16秒 | 你不知道它有没有听到，也不知道是网络卡住，还是识别失败。 | 两个未知状态依次亮起。 |
| 16–24秒 | 没有为小概率弱网重做一套复杂兜底，而是先解决“不知道”。 | “网络差：继续等待”与“完全断网：明确停止”两张状态卡。 |
| 24–31秒 | 用 Mac 自带工具复现低带宽、丢包和延迟。 | Network Link Conditioner 真实截图，参数依次点亮。 |
| 31秒至结尾 | 很多体验问题，不在规划里，而在真的用起来以后。 | 最终判断卡。 |
